---
title: How to Play D&D by Post
---

Dungeons & Dragons works beautifully by post. The exploration, roleplay, and problem-solving that fill most of a session translate directly to writing; only the live back-and-forth changes. Here is how to keep a D&D game moving when the group plays one post at a time.

## Set the pace before the first post

The single biggest question in play-by-post is: **how often is everyone expected to post?** Agree on it up front.

- A common rhythm is **once a day on weekdays**, with weekends optional.
- For combat, many groups switch to **once a day per turn**, keeping initiative moving.
- If someone will be away, the **AFK status** tells the table so the game does not stall waiting.

Write the expectation somewhere everyone can see it. A campaign that knows its own pace rarely dies waiting on a silent player.

## Run the easy parts in the open

Play-by-post rewards separation. Keep the table together for the moments that need it, and split off for the rest.

- Start a **scene** with a short prompt: where the party is, what they see, what is at stake.
- Let players post their actions and dialogue in any order during exploration. You do not need strict turns outside combat.
- Use **replies** to answer a specific post, and **whispers** to pass a private note to the Game Master.

## Use scene breaks, not walls of text

Long posts are hard to read on a phone. Structure beats length.

- Open with a **scene break** when the location or time changes.
- Quote the line you are reacting to instead of restating it.
- Put **bold** on the one thing that matters in a post — a name, a threat, a roll.

## Keep combat readable

Combat is the one place where order matters, so lean on the tools.

- Set the **status bar** to show initiative and the active player.
- Use the **dice roller**: tap `1d20+5` in a post to roll it, or open an [ability check](/help/ability-checks) with the modifier pre-filled.
- For games that read each die, use **pool** rolls (`5d6`) or **success** rolls (`5d6>=4`).
- Announce the turn clearly and let the next player post when they can.

## Give everyone something to do

In a live game it is easy to ask the quiet player a direct question. Online, do it in writing.

- Address a character by name and ask what they do.
- Use **NPCs** to have an ally or villain speak directly to a specific player.
- Let downtime happen between scenes so players can pursue their own goals.

## Keep the table comfortable

Safety matters more, not less, when the group is not in the same room. Role by Post includes **safety tools** built into the channel:

- **Lines and veils** record what the group wants off-screen or handled carefully.
- An **anonymous X-card** lets any player flag a moment without having to say so out loud.

Read the [safety tools guide](/help/safety-tools) and set them up before the first scene.

## Start playing

Create a campaign, invite your group, and post the opening scene. [Role by Post](/features) handles the timeline, dice, NPCs, and notifications so the story can keep moving between sessions. New to the format? Start with [what play-by-post is](/play-by-post), or read [how to run a play-by-post game](/how-to/run-play-by-post).
