# Discord — server admin outreach

Private message template for reaching the admins of PbP / Shadowdark / OSR
Discord servers. The ask is permission to be listed or mentioned in their
channels — **no cold link-drops** in their servers. Send one targeted DM per
server, from an account that has been in the server (or at least read it) long
enough not to look like a drive-by.

Tracked link (UTM): <https://rolebypost.com/features?utm_source=discord&utm_medium=community&utm_campaign=server-outreach>

## Targeted servers (starting list)

- Play-by-post / PbP-focused servers
- Shadowdark servers
- OSR / old-school servers

Keep this list updated as servers are contacted and as responses come back.

## DM template

```text
Hi <name> — I'm the dev behind Role by Post, a free text-first play-by-post app (not a VTT). I'll keep this short and won't drop links unless you want them.

<one line on why this server specifically: e.g. "I saw #looking-for-group runs a lot of async games" — prove you actually looked.>

If it's useful to your members, I'd be happy for the app to be mentioned wherever you list play-by-post tools, or to answer questions if you ever want a #resources note. No obligation, and I won't post in the server unless a mod invites it.

If you'd like to take a look first: <tracked link>

Either way, thanks for running the place.
```

## Etiquette

- **Ask, don't post.** The offer is "may we be listed / may I answer questions", not a link in the general chat. Only post where a moderator says it's welcome.
- **Read the rules first.** Many servers ban unsolicited DMs or promo entirely; respect a "no self-promo" rule and don't message the owner "just in case".
- **One DM per server**, to a mod/admin (not every mod in the server), and don't follow up more than once.
- **Personalise the middle line.** A generic blast is easy to spot and gets ignored or reported.
- **Account identity:** DM from the project's own handle, not a personal alt, and make the purpose obvious in the first sentence.
- **No link-drops:** the template offers the link and waits for a yes. Don't paste it into a server you haven't been invited to share it in.

## Posting notes

- **UTM:** the tracked link lets GA4 attribute any resulting traffic to `discord`/`server-outreach` (consent-gated, so expect undercounting). Discord strips nothing; the URL survives.
- **Outcome tracking:** record contacted servers and whether each said yes/no/ignored in this file so the list stays useful.
