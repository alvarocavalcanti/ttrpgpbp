# RPG.net — Ye Olde Tavern

Ready-to-paste **game ad** for the
[RPG.net](https://forum.rpg.net/) *Ye Olde Tavern* forum (the play-by-post /
recruitment board). Like the Giant in the Playground ad, this recruits players
for an actual free game run on Role by Post — a game ad, not a tool ad. Fill the
`[brackets]` before posting.

Tracked link (UTM): <https://rolebypost.com/features?utm_source=rpgnet&utm_medium=forum&utm_campaign=tavern>

## Title

```text
[Recruitment][<system>] <short hook> — free play-by-post game
```

Example:

```text
[Recruitment][Shadowdark] The Sunken Barrow — free play-by-post game
```

## Body

```text
**Looking for:** <n> player(s) for a <system> play-by-post game.

**The pitch:** <one or two sentences on premise, tone, and what the table will be doing.>

**System:** <system and edition>. Beginners welcome — I'll help anyone new to it.

**Platform:** We're playing on Role by Post, a free text-first PbP app. No cost, no VTT; it keeps the writing, dice, turn status, and safety tools in one place and works from any browser or phone. More here: https://rolebypost.com/features?utm_source=rpgnet&utm_medium=forum&utm_campaign=tavern

**Pace:** Asynchronous. I'm aiming for <one post per player per day / a few posts a week>; slower is fine as long as we keep moving.

**Starting point:** <character creation notes — level, point buy, anything players need to know>.

**Safety tools:** Lines and Veils plus an anonymous X-card, built into the app. We'll sort content boundaries at the start.

**To join:** post here or PM me with a short character concept, and I'll send an invite link.
```

## Posting notes

- **Forum:** RPG.net → *Ye Olde Tavern*. Confirm the current subforum name and that recruitment posts belong there before posting; RPG.net reorganises forums from time to time.
- **It must be a real game.** Decide the system, schedule, and at least one open slot before posting — a placeholder ad that never starts reads as spam.
- **Account history:** RPG.net is wary of new-account promotion. Use an account with some posting history, or take part in a thread or two first.
- **One thread per game:** edit the title/OP with updates ("Full", "Closed") instead of reposting or bumping.
- **Do not cross-post this verbatim** with the Giant in the Playground ad at the same time; each forum gets its own adapted post.
- **Link:** use the tracked link above so GA4 can attribute sign-ups to RPG.net (consent-gated, so expect undercounting).
