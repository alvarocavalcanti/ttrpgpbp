The **Channel Status Bar** sits at the top of the channel and keeps the group's shared state visible — initiative order, timers, NPCs, or anything else.

## What it shows

- **Free-form text** with markdown and emoji support, up to 2,000 characters
- **Active player(s)** — a structured field naming who's up, which drives notifications
- When collapsed, the first line stays visible

## Who can edit

The **GM** edits the status bar at any time. The GM can also set the active player(s) while composing a message — this updates the status and notifies the active player.
