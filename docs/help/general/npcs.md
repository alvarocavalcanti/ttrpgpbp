The GM can speak as **NPCs** (non-player characters) with their own name and portrait. NPC features are GM-only.

## Speaking as an NPC

1. Open the **"+"** options in the message composer.
2. Select **NPC mode** and type a name.
3. The message is attributed to the NPC.

## Creating NPCs on the fly

- A **new name** creates the NPC automatically with a random portrait.
- An **existing name** reuses that NPC's saved portrait.

## Portraits

GMs can search game-icons.net by name or tag to **pick a specific portrait**, or re-randomize at any time. Portraits are curated first, with full search as a fallback.

## Roster

Each channel keeps a persistent **NPC roster**. Existing NPC names autocomplete when you type, and the roster is shared across the channel's GM.

## NPC messages

- NPC messages work with **whispers**
- They appear in **search**, **chat export**, and **push notifications** attributed to the NPC
- Names and portraits are **snapshotted** on each message, so past messages stay stable if an NPC is later renamed or re-pictured
